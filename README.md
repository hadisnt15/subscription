# Subscription Management System

Web-based application for managing subscription packages, payments, and user subscriptions.

## Features

- User registration and authentication.
- Subscription package management.
- Subscription ordering.
- Payment proof upload.
- Payment verification (approve/reject).
- Subscription history and status monitoring.
- Automatic subscription expiration.

## Tech Stack

- Laravel 13
- React 19
- Vite 8
- Tailwind CSS 4
- MySQL 8
