# Subscription Management System

Web-based application for managing subscription packages, payments, and user subscriptions.

## Features

- User registration and authentication.
- Subscription package management.
- Subscription ordering.
- Payment proof upload.
- Payment verification (approve/reject).
- Subscription history and status monitoring.
- Automatic subscription expiration.

## Tech Stack

- Laravel 13
- React 19
- Vite 8
- Tailwind CSS 4
- MySQL 8

## How to Use

1. Register an account.
2. Login to the application.
3. Browse and select a subscription package.
4. Submit a subscription order.
5. Upload payment proof.
6. Wait for admin payment verification.
7. Check your subscription status and history.
